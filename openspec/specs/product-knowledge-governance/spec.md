# product-knowledge-governance Specification

## Purpose
将失败、返工、人工修订和近失误沉淀为可检索的项目或共通知识，并在不膨胀 Worker 上下文的前提下，把经过验证的经验转化为下一次运行可执行的防线。

## Requirements

### Requirement: 错误事件必须在发生时采集

系统 MUST 采集 Worker 失败或阻塞、测试失败、验收失败、部署失败、人工修订和成功前近失误，并保存证据引用、运行、功能和验收关联。

#### Scenario: 验收断言失败
- **WHEN** 功能点的验收断言失败或实际结果与预期不一致
- **THEN** 系统 MUST 立即追加错误事件，不得只保留最终汇总

#### Scenario: 重试后成功
- **WHEN** 操作经过重试或人工干预后成功
- **THEN** 系统 MUST 记录 `near_miss`，并保留原始失败证据

### Requirement: 错误必须异步提出范围归属

系统 MUST 先将新错误标记为 `unknown`，再由后台分类 Worker 根据可移植性、根因来源、修复位置、复现范围和误伤风险提出 `common`、`project` 或 `hybrid` 建议。

#### Scenario: 新错误不阻塞主流程
- **WHEN** 错误事件已写入但分类尚未完成
- **THEN** 主流程 MUST 能继续或按自身门禁结束，分类任务在后台处理

### Requirement: 公共知识必须经过晋升门禁

系统 MUST 只有在经验脱敏、可脱离项目复用、具有复现或规范依据，并通过独立复检后，才允许写入公共 Guardrail。

#### Scenario: 项目错误不能直接污染公共库
- **WHEN** 错误依赖项目 API、数据模型或环境路径且只在一个项目出现
- **THEN** 系统 MUST 将其保持为项目知识，不得自动发布到公共库

### Requirement: 人工覆盖优先于自动建议

系统 MUST 支持人工覆盖知识的范围、状态、严重级别、解决方案和项目归属，并将人工决定作为后续读取的最高优先级；人工可以选择移动归属或复制复用，所有操作都 MUST 保存版本和归属历史。

#### Scenario: 人工将公共候选改为项目问题
- **WHEN** 操作者判定后台建议的 `common` 依赖当前项目领域规则
- **THEN** 系统 MUST 保存覆盖原因，并按 `project` 范围停止公共检索

#### Scenario: 人工移动归属

- **WHEN** 操作者将问题从项目 A 移动到项目 B
- **THEN** 系统 MUST 追加来源项目、目标项目、操作者、原因和版本，不得覆盖或删除原项目历史

#### Scenario: 人工复制公共规则

- **WHEN** 操作者将公共规则复制为项目 A 的适配规则
- **THEN** 系统 MUST 创建新的项目引用并保留公共规则版本关系，公共规则仍可被其他项目继承

### Requirement: Worker 只能读取冻结知识快照

系统 MUST 在每次运行开始生成包含已发布公共规则和当前项目规则的有限大小快照，并禁止 Worker 默认读取全部历史错误或候选记录。

#### Scenario: 历史错误过多
- **WHEN** 知识库超过当前运行的上下文预算
- **THEN** 系统 MUST 按范围、严重级别、重复次数、置信度和时效选择有限条目，并保留完整证据的引用

### Requirement: 已验证知识必须可作为 AI 交互上下文

系统 MUST 将已验证的公共知识和项目知识转换为有限 RSI 快照，并保留范围、来源、验证状态和证据引用。

#### Scenario: 任务开始读取 RSI
- **WHEN** AI 工具开始处理项目任务
- **THEN** 系统 MUST 先提供全局 RSI，再提供项目 RSI，并将当前任务事实作为最高优先级上下文

#### Scenario: 未验证候选不进入默认上下文
- **WHEN** 候选知识仍为 unknown、pending 或未通过公共晋升门禁
- **THEN** 系统 MUST 只保留候选引用，不把候选内容作为默认可执行规则注入

### Requirement: RSI 写回必须保留反馈证据

系统 MUST 将失败、近失误、成功前修正和人工反馈写回项目事实源，并支持后续按公共或项目范围治理。

#### Scenario: 重试后成功
- **WHEN** AI 工具修复失败并最终通过验证
- **THEN** 系统 MUST 同时保留原始失败、修正动作、验证证据和可提炼的 near_miss 关系
