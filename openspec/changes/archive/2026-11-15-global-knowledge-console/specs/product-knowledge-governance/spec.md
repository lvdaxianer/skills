# Spec Delta

## MODIFIED Requirements

### Requirement: 人工覆盖优先于自动建议

系统 MUST 支持人工覆盖知识的范围、状态、严重级别、解决方案和项目归属，并将人工决定作为后续读取的最高优先级；人工可以选择移动归属或复制复用，所有操作都 MUST 保存版本和归属历史。

#### Scenario: 人工将公共候选改为项目问题

- **WHEN** 操作者判定后台建议的 `common` 依赖当前项目领域规则
- **THEN** 系统 MUST 保存覆盖原因，并按 `project` 范围停止公共检索

#### Scenario: 人工移动归属

- **WHEN** 操作者将问题从项目 A 移动到项目 B
- **THEN** 系统 MUST 追加来源项目、目标项目、操作者、原因和版本，不得覆盖或删除原项目历史

#### Scenario: 人工复制公共规则

- **WHEN** 操作者将公共规则复制为项目 A 的适配规则
- **THEN** 系统 MUST 创建新的项目引用并保留公共规则版本关系，公共规则仍可被其他项目继承
